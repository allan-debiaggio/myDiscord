Objectifs du projet :
  • un serveur capable de gérer la connexion simultanée de plusieurs clients
  • l'envoi et la réception de messages en temps réel
  • la navigation entre différents canaux de discussion
  • la gestion de rôles utilisateurs (utilisateur, modérateur, administrateur)
  • la persistance des données via une base de données PostgreSQL
  • le chiffrement des données privées pour la sécurité des échanges privés
  • l'intégration d'une interface graphique pour une expérience utilisateur plus intuitive et agréable
Outils techniques & compétences clés
Réseau en C : sockets POSIX, multi-threading (mutex)
Base de données : PostgreSQL via libpq
Chiffrement : sécurisation avec libsodium
Interface graphique : ncurses (terminal), GTK (bureau)
Conteneurisation : usage de Docker pour l'exécution multiplateforme (Windows/Linux)
