# Présentation My Dispute Messenger

Cette présentation interactive a été réalisée pour la soutenance du projet My Dispute Messenger, un clone de Discord développé en C avec une interface terminal ncurses.

## Contenu
- Slides animées et interactives sur le projet, l'équipe, les choix techniques, la structure, la démo et les perspectives.
- Illustrations, animations et effets néon/cyberpunk.

## Utilisation
1. Ouvrez le fichier `presentation.html` dans votre navigateur web (Chrome ou Firefox recommandé).
2. Naviguez entre les slides avec les flèches du clavier ou les flèches à l'écran.
3. Certaines slides affichent des éléments ou animations au fur et à mesure, sur pression d'une touche ou d'une flèche.

## Prérequis
- Un navigateur web moderne.
- Toutes les images nécessaires doivent être présentes dans le dossier racine.
